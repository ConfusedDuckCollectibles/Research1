# Independent exact square boundary for all n≥9

Research1 companion note, November 2026. Not peer reviewed. This closes the shared-marker C4 anchor graph for every n≥9 (the minimum n=2r+1 with r=4), with the same two-layer weighting conclusion as completion.md. It independently verifies the square boundary by a different construction from the reported Carbon all-size proof. It is not a first-priority claim or a general H result. The r≥5 theorem has its separate complete replay.

For n≥32 use proof.md: the PSD argument and all displayed bounds only require degree-two anchors, one distinct tip per deleted edge, and n≥2r+1. Ranges for five-tip compatibility are not invoked in that proof; the mask is inverted on its compatible subspace directly. With r=4 the same argument applies. At n=22,…,31 use the verified triple-type criterion on fixed r=4; CYCLE-SQUARE-TYPED provides exact squared ratios, all <1. At n=15,…,21 use the factored actual locked error and exact integer-dyadic Frobenius checker, with κ>0, as in CYCLE-ALL-R5; CYCLE-SQUARE-ACTUAL gives the seven checks. These calculations use no spectral extrapolation through the low n.

At n=9,…,14 the earlier five-tip disjoint repair theorem is unavailable: the bipartite disjointness graph on pairs of four tips is disconnected. Instead solve the smaller **exact dihedral and leaf-symmetric** repair problem as follows, independently at each n.

1. Form the factored exact locked deficit D0 and the masked map T(D)=M(EDE) exactly as in CYCLE-ALL-R5. Bounded floating conjugate gradient is only a candidate generator. Take one dyadic rounded value for each (unordered) locked pair orbit and use it on the entire orbit. The orbit invariant is canonical under the eight dihedral symmetries of the square and swapping the two triples: on old core coordinates it uses the two core masks, and among untouched leaves the three counts (common, first-only, second-only). This is complete because the leaf action is unrestricted and the shifts/reflections act on each tip through its labeled edge.
2. With this exact rational D compute exact T(D), R0=D0−T(D). Verify all incident-coordinate compatibility literally. Rather than bound ||EDE||₂ by ||D||_F (insufficient at n9 and n10), calculate
       ||EDE||_F² = <D,EDE>_F = <D,T(D)>_F
   exactly, since EDE is an orthogonal projection on the symmetric matrix space and D is supported on the mask. Check that it is <(μ−α)² with α=1/100 for n9 and 1/4 otherwise. This proves the pre-repair Kneser gap on the old incidence complement.
3. Introduce one variable per unordered disjoint pair orbit, again with the same complete canonical representation. Deviations are supported on disjoint pairs by construction. For a nonincident row U and tight coordinate i, the orbit of (U,i) is represented by the canonical core mask for U, its number of leaves, and the core label i (or a generic outside leaf if i is an untouched point). For one representative equation of each such orbit, count intervening disjoint pair variables and solve the exact rational system with RHS −(R0 X_I)(U,i). Check that the RHS agrees on every orbit class. Only zero leftover equations and exact back-substitution are accepted. In addition verify **every literal** old row's tight coordinate equation using the resulting disjoint coefficients; the success does not rely on the orbit classifier representing all row coefficient symmetries.
4. Compute exact max absolute row sum of R0+Δ (disjoint supports make addition of absolute sums valid). Apply the explicit coupled Schur gap on the complement of tied star differences from CYCLE-ALL-R5, now with the verified α just above. Both unperturbed and repaired blocks kill every tied difference exactly; the exact max-row bound is strictly smaller than the Schur gap at each n.
