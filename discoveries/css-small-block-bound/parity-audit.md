# Independent audit and source comparison

**Finding.** The disjoint-triple theorem, rank-one cutoff, restricted distance formula and equality when \(d_X\ge2\) and \(h\ge2r\) all hold as stated. Dropping the disjointness requirement at rank above one gives a false theorem, with the six-block example in [disjoint-parity.md](disjoint-parity.md). The rank-one implication uses the physical row presentation only to infer existence of a residual triple; the structural hypothesis and restricted minimum are otherwise intrinsic. Recommend an addendum to the existing CSS snapshot, not a stand-alone breakthrough, independent new construction, or novelty claim about rank-two coding bounds.

### Main stress checks

- \(U=\ker(\pi|_K)\) exactly, including pinned coordinates. The expression \(K/U\) must be identified with the parity image on unpinned components, not with arbitrary columns of an unreduced generator matrix. A rank-one nonzero image is generated by at least one presented row, so \(W_Z<4D\) is sufficient. At \(W_Z=4D\), a single parity on four equal physical blocks gives an immediate counterexample to “rank one implies a triple.” At higher rank and \(W_Z=3D\), the six-block overlap example violates the numerical triple formula, not just the recognition criterion.
- Increment \(j\) is relative to the image of all previous regions in the full logical quotient, so it is not necessarily the local rank. For an increment-two triple, all three nonzero pairs survive even modulo earlier images. The physical supports remain disjoint regardless of logical relationships. The two-disjoint-triple control with a crossed \(X\) stabilizer has relative total rank three, although each triple maps with rank two in isolation. The stronger surplus-count bound there is \(n_L\ge6D\), while the original proposed bound gives \(5D\).
- The exact minimum uses the full stabilizer row space on the support of an individual pair or indicator, not a quotient modulo earlier regional images. For several disjoint parities (of any size), partition the even support on each region into pairs. A globally nontrivial word cannot have all pieces globally trivial. The \(d_X=1\) control confined to small blocks has restricted distance two, and the \(h=0\) control has infinite restricted distance while the full code has \(k=2\).
- For \(D\) an integer, the odd-distance family \([[5D,2,(3,D)]]\) and the even family are formed by standard repetition concatenations; the equality statement is only a parameter statement for the specified subclass. \(h=r=0\) is a vacuous bound, and for \(d_X=1\) the advertised construction must not use \(\lfloor d_X/2\rfloor=0\). The optional surplus lower bound is an inequality, not an assertion of global attainability for those parameters.
- The general single-parity count has an elementary optimization. At any fixed increment \(j\), take a smallest component of size \(a\) as reference and use \(j\) surviving pairs with that reference; every other component is still at least \(a\). The abstract lower cost can be attained for each prescribed \(a\) using \(t-j\) copies of the reference label of size \(a\) and \(j\) independent other labels at cost \(\max(a,d-a)\). This is local weighted quotient sharpness, not proof that each partial profile is attainable by an intrinsically contracted physical CSS code. In particular, residual \(\operatorname{row}A\) cannot have weight-two words; when \(d\ge3\) this means two one-block components cannot lie in the same parity region (their pair would necessarily be a nontrivial X weight-two word). The candidate inequality deliberately does not use this further restriction.

### Primary-source overlap

1. [J. H. Griesmer, Theorems 1–2, 1960](https://www.bitsavers.org/pdf/ibm/IBM_Journal_of_Research_and_Development/045/ibmrd0405M.pdf), gives the exact increment-two numerical cost \(d+\lceil d/2\rceil\). To apply it, use unit-block indicator expansion of the locally injective two-dimensional subspace; its nonzero words all represent logical X. In fact any disjoint spatial region supporting \(j\) new logical classes admits a linear section of dimension \(j\), and local classical Griesmer then bounds its length in original blocks. Thus the core triple penalty is a direct local use of classical Griesmer and rank additivity, not a new coding inequality in isolation. Counting the third component also improves the increment-one Griesmer value.
2. [Luo–Ezerman–Ling, Theorem 3.1](https://dr.ntu.edu.sg/server/api/core/bitstreams/5ddfbc8d-7d82-4e4a-9bd9-e3f5eaa3595e/content), applies Griesmer to complementary nested CSS subcodes for the global bound \(n+k\ge\sum_{i=0}^{k-1}\lceil d_X/2^i\rceil+\sum_{i=0}^{k-1}\lceil d_Z/2^i\rceil\) in the binary case. This is not the structural \(n_L\) bound; for the odd-distance two-logical family and \(D\ge2\), the global bound is \(n\ge3+D+\lceil D/2\rceil<5D\). Their §3.3 also uses repetition to scale one distance, so the operation itself is established. [Sarvepalli–Klappenecker, 2010](https://doi.org/10.1103/PhysRevA.81.032318) gives an earlier symmetric quantum Griesmer analogue.
3. [Haah–Preskill, Lemma 2, Eq. (3)](https://arxiv.org/pdf/1011.3529) already gives the oriented complementary-support dimension \(h=k-\ell\). [Sabo et al., §III.A Lemma 1](https://journals.aps.org/prxquantum/pdf/10.1103/PRXQuantum.5.040302) gives the same copying orientation, with \(d_X\) unchanged and \(d_Z\) multiplied by the uniform copy width. [Cao–Lackey §5 Theorem 3](https://arxiv.org/html/2507.13496v1#S5) gives more general conjoining from bit and phase repetition primitives. None of these construction precedents distinguishes the new example as a code-construction novelty.
4. [Wang–Liu–Li–Kubica–Gu §III.1](https://arxiv.org/html/2601.15446v1#S3.SS1) establishes the \(d\le2\) obstruction at maximum **physical** check weight three, a different statement about \(\min(d_X,d_Z)\). Their [Theorem III.15](https://arxiv.org/html/2601.15446v1#S3.SS3) uses whole-component parity reduction for **subsystem gauge** weight two. These antecedents neither state nor imply the disjoint residual parity certificate for this asymmetric stabilizer contraction. [Cheng–Guo–Pan Lemma 5.1](https://arxiv.org/html/2611.08247v1#S5) proves the generic “nontrivial minimum support has no proper zero-syndrome piece” principle, of which the restricted minimum reduction is a direct structured example.

No reviewed source stated the full conjunction: intrinsic reduction to \(R\), disjoint-triple recognition from the projected span, exception-aware \(k-\ell\) physical charge, and exact short-support test for this CSS class. That is a scoped literature observation, not a priority assertion. It does not justify statements about all low-weight Z stabilizers, tomography, measurement circuitry, or noise thresholds.

### Exact independent replay

From this directory, run:

```sh
python3 audit-parity.py
sha256sum -c SHA256SUMS
```

The script uses standard-library Python only, imports no code or fixtures from the source note or Dreamer, and generates physical checks independently. For each physical control it exhausts supports through the first physical X/Z witnesses and enumerates all allowed supports if restricted distance is infinite. It computes \(h\) separately by rank on the **physical** shortened support, reconstructs intrinsic pair partitions directly by row-space membership, and compares the candidate restricted minimum when its structural hypothesis passes. The abstract section exhausts every binary stabilizer-equivalence subspace of each listed regional X kernel, with dimensions through six. It tests positive integer lengths 1–3 through six components and 1–2 for the seven/eight-component controls, and each candidate distance from one through the actual restricted minimum (targets one through five for zero logical quotient). These are abstract quotient tests, not claims of exhaustive enumeration of all physical CSS codes. See [audit.log](audit.log) for counts and negative controls.
