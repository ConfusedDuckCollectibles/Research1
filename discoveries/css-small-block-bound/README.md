# A qubit-count limit for a class of quantum error-correcting codes

How few physical qubits can protect a logical qubit against two kinds of
errors? For a class of CSS codes, a simple rank calculation can rule out
impossible designs without an exhaustive search.

Group physical qubits linked by pair X stabilizers. Let `D` be the target
Z distance, `d_X` the X distance, and `k` the number of encoded qubits.
The small groups can support some of the protection requirements. Let
`ell` count the independent Z logical operators that can be confined to
those groups. When the projected Z constraints on large groups are
generated by one- and two-group checks, the large groups alone require
at least **`D × d_X × (k − ell)` physical qubits**.

The correction matters: a 32-qubit example attains the limit with one
small-group logical operator; ignoring it would wrongly rule out the
example. A separate 24-qubit control shows how the rank test can recover
the relevant one- and two-group constraint structure when the displayed
checks hide it.

This is a narrow mathematical design constraint. It does not claim a
new code record, an error threshold in hardware, or a general quantum
LDPC bound. Repetition blocks and complementary-support counting are
known; this note isolates the exact small-group correction and an
intrinsic test for when it applies. See the [proof](proof.md) and
[independent audit with prior work](audit.md). Not peer reviewed.

### Reproduce

Use Python 3, no packages required:

```sh
python3 verify.py
python3 audit.py --nmax 6
```

The independent replay checks all eight supplied designs, the extra
24-qubit case, and 98,780 small CSS row-space pairs. The code controls
are not a substitute for the proof.
