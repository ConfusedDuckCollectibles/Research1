# Independent audit: matching from two unlinked ordered supply margins

**Scope.** Anonymous integer tokens and unit requests, entirely synthetic; not a clinical compatibility model, policy, or allocation. Supply all present at time zero, no replenishment, no other feasibility constraints, and every request q requires a token at its known service slot. If “deadline” instead allows arbitrarily early service, the stipulated expiration test need not describe feasibility. Inclusive expiry and ordered threshold semantics are explicit. A plan may depend on the actual linked token attributes **after they are revealed**; preselecting robust request IDs does not mean blindly selecting labeled tokens. No assumptions about distributions, correlations, or clinical ranks.

## One construction, all neighborhoods at the cutoff

Label separately ranked supply lists by integers 1,...,N (best first; resolve ties arbitrarily and thresholds still select complete prefixes). A completion is a permutation π matching labels; every realizable integer cross-table can be lifted to such a permutation via within-tie labels. If request q needs a top-a_q compatibility strength and a top-b_q expiry, its actual neighborhood is
`S_pi(q)={i: i<=a_q and pi(i)<=b_q}.`
Its cardinality is at least g_q=(a_q+b_q−N)_+ by inclusion-exclusion even if a or b is zero.

At any integer z in [0,N], pair top z ranks together and reverse the other ranks: π_z(i)=i for i≤z and π_z(i)=N+z+1−i otherwise. Every request with g_q≤z has a_q+b_q≤N+z, so no eligible pair has i>z; its two rank inequalities would contradict the prescribed tail sum. Thus **all** such neighborhoods simultaneously lie within the same stock pool of size z. For any subset U of request IDs, set z=max(g_q : q∈U), with z=0 for empty U. Every actual union N_pi(U) has size ≥z, and π_z puts it within a z-pool. Its sharp minimum is exactly z. The witness depends on the objective's cutoff: q=(a,b)=(1,2) and (2,1) with N=2 have minimal union when the two top attributes coincide, while (1,1) is minimized when the two top attributes do not coincide.

## Total, fixed request subset, and matroid

For a fixed graph, Hall minimax (or the source/sink cut of unit matching) gives optimum cardinality
`min_U [|D\U|+|N_pi(U)|]`.
More generally, if the matched request set must be independent in a fixed matroid M, replace |D\U| by r_M(D\U). This is exactly the older Aigner–Dowling fixed-graph rank min cut. One can also derive it by matroid intersection between M and the request-side transversal matroid, expanding r_T(U)=min_(W⊂U)[|U\W|+|N(W)|]. The minimizing U for fixed W may be taken U=W, because r_M(D\W)≤r_M(D\U)+|U\W|. The two finite minima over U and π commute. Since the neighbor minimum is the max g on U, writing E_z={q:g_q>z} gives the sharp robust value
`min_(0<=z<=N) [z+r_M(E_z)]`,
and |E_z| replaces rank with the free matroid. Indeed, given U choose z=max g_U and E_z⊂D\U. Conversely at any z use U={g≤z}, whose max g is at most z. Optimum only needs z=0 or a realized score since rank is constant between scores; N=0 works.

The simultaneous cutoff construction additionally identifies **all individually preselectable request subsets**. A subset I is robustly matchable iff it is matchable in the virtual prefix graph where request q sees fictitious items 1,...,g_q. If the ordered scores of I satisfy g_(i)≥i, greedily select an unused actual neighbor for each q, because fewer than i units have been used. If that test fails at index i, take z=g_(i); π_z forces at least i>z requests of I onto just z possible units. This argument needs no problematic independent per-request attainment. The virtual graph is itself one finite transversal matroid, but need not be a realizable stock completion.

A fixed set of optimum V_M request IDs can be protected across stock worlds. One route is apply fixed-graph rank equality to the virtual prefix graph. The author instead greedily selects a nested basis I of M in decreasing g; after every tie block the prefix has r_M(E_z) chosen IDs, and dropping the smallest-g maximum prefix deficit yields a virtual match of size V_M. Both routes give the same result. Continuing with an already chosen quota set, a virtual augmenting path never unmatches a previously covered request, so a robust maximum total can be attained simultaneously with feasible group floors.

## Protected counts

For disjoint groups D_j and 0≤k_j≤|D_j|, a fixed stock completion allows all lower floors iff every request subset U satisfies 
`Σ_j (k_j−|D_j\U|)_+ ≤ |N_pi(U)|`.
Independent derivation: source → class j has capacity k_j, class → each of its requests capacity 1, request → eligible stock sufficiently large, stock → sink capacity 1. For fixed set U of requests on the source side, optimize each class vertex's cut side independently; its group cost is min(k_j,|D_j\U|), and the closure's stock cost is |N_pi(U)|. Integral capacity and the max-flow min-cut theorem give necessity and sufficiency. Universal floors therefore hold iff for each z,
`Σ_j (k_j−|D_j∩E_z|)_+ ≤ z`.
Sufficiency can be checked directly by choosing top k_j scores in each group and testing the virtual prefixes. This uses disjoint lower classes and unit fill; it is not a holdback guarantee at intermediate times, arbitrary overlapping floors, or weighted objective. Exact throughout, including tied margins and no serviceable requests.

For a nonmatroid fixed hereditary policy, adaptively optimal request selection can be strictly better than the best fixed robust subset. Use N=2, requests q_1=(1,2), q_2=(2,1), q_3=(1,1), q_4=(2,2) in (a,b) coordinates; only allowed sets are subsets of {q_1,q_2} or {q_3,q_4}. The reversed world admits the first pair but not second, while the aligned world admits the second pair but not first. Worst adaptive cardinality is 2, robust fixed cardinality 1. This falsifies extending the fixed-ID conclusion by merely replacing matroid with hereditary.

## One sharp menu across all scopes, not one universal adverse completion

If N≥1 the N canonical scenarios z=0,...,N−1 suffice for all demand scopes: if a minimizing cutoff is z<N pick it; if the minimum is only attained at N, the robust optimum is N and hence every completion already has optimum N. At N=0 the all-empty completion is trivial.

Worst-case N is necessary when all stock labels have distinct ranks, in a common request universe with N copies per permitted box threshold. For scope z include all boxes a+b=N+z, a,b in 1..N; their union is precisely i+j≤N+z (z=0,N=1 is trivial). Each compatible stock item can take its own copy of any eligible request type, so maximum service equals the triangle occupancy. Its minimum is z by the prior construction. Equality forces the weak pairs' row and column ranks to be exactly 1,...,z, and every other sum exactly N+z+1: the fixed total N(N+1) equals the elementary lower bound z(z+1)+(N−z)(N+z+1). In particular π(N)=z+1, so the minimizing families are disjoint across all z<N. Exactly z! permutations attain the z-case (arbitrary top-block pairing, forced tail). This counts adversarial scenarios required to *attain* every scoped optimum, not a computational lower bound for calculating the closed formula and not a requirement that real tied data always need N.

## Two further closures

**Best stock pairing and all possible maxima.** An integral max-flow network with a distinct node for every compatibility label i, a capacity-one split for every request q, and distinct expiry labels j finds the unrestricted best cardinality. Match used compatibility/expiry labels along each unit path and pair unused labels arbitrarily to finish the stock; every realized matching induces such paths. Do not instead replace g by the individual upper degrees min(a,b): even the two-request N=2 example above has identical degree maxima but pairing top with top gives just one match instead of the best two.

Possible cardinalities of optimal adaptive service between the minimum and maximum have no integer gaps, even under a fixed nonempty hereditary feasibility family. Transpose two expiry labels. For two affected tokens this swaps aligned weak/strong against crossed. If two previous assignments are involved, from aligned to crossed preserve whichever request used the weak token on one of its dominators; from crossed to aligned the strong token preserves either request. If at most one was involved simply drop at most one. Keep all unaffected assignments. Heredity permits deletion, so each swap changes the optimum by at most one in either direction. The finite permutation graph is connected and supplies every intermediate integer. It does not give no-gap claims for arbitrary nonhereditary groups or joint vectors.

**Demand linkage also unknown.** Within each disjoint class j, if requested compatibility and service time margins are separately known but their same-request pairing is independently free, the easy set E_z={g>z} in requested-clause coordinates is a downward set. Each (p,t) corner generates the rectangle with a_j(p) compatibility-prefix count and b_j(t) time-prefix count. By the same union lemma applied to *demand* ranks, the minimum L_j(z) of the easy-count over that class equals max of 0 and a_j(p)+b_j(t)−M_j over the easy corners. Include only available marginal rank events; empty easy set has value 0. Worst total is min_z[z+Σ_j L_j(z)]; robust protected floors require Σ_j(k_j−L_j(z))_+≤z simultaneously in z. The upper witnesses use the optimizing z for stock and separately each class, not a universal jointly adverse unlinked demand pairing. This extension has no meaningful fixed-request-ID guarantee before the attributes are revealed.

In three axes single-request lower-intersection degrees no longer determine total. Two stock items each axis with one high item, three requests requiring high on a pair of axes and wildcard on the third. Each single g is zero yet some stock item has ≥2 highs; at most one item can since there are only three highs. Actual optimal cardinality is one in every assignment. This is a geometric two-axis restriction, not a claim that actual compatibility is two dimensional.

## Synthetic fixture and replay

Twenty initially available stock tokens, ten per tier and expiry counts (9,2,9). Nine strong/time-1, one strong/time-2, one base/time-2, nine base/time-3 requests; their g values are 10,1,11,9. Worst service is 11; strong row (0,1,9) supports it. Best is 20 with strong row (9,1,0). Direct group flow over all 28 latent contingency tables gives every integer 11–20: three worlds for each 11,..,19 and one for 20. Therefore 45 percentage points is a sharp synthetic width. The joint guarantee for strong pool A and late base pool B is k_A+k_B≤10 under 0≤k_A≤10, 0≤k_B≤9. Each 7 floor individually holds, while both floors jointly fail in the worst world.

Run `python3 check.py` (standard Python only). Item-by-item matching enumerates every possible served subset without using the target min-cut routine. The independent checks cover 66,067 rank-rectangle scope minima, 4,312 stock-world matching/matroid/quota checks, all menu minimizers through N=8, all 28 main-case tables, 640 both-demand-and-stock worlds, 225 explicit flow/no-hole cases, and the counterexamples. They support the stated calculations; the proofs establish the unbounded theorems.

## Closest primary prior and recommendation

- [Makarov, Russian 1981 / English 1982](https://www.mathnet.ru/eng/tvp3510) gives the sharp fixed-marginal sum-event bounds. The menu's rank-sum triangles are an exact finite instance. [Frank–Nelsen–Schweizer (1987)](https://link.springer.com/article/10.1007/BF00569989) extends the copula method beyond addition to monotone binary operations. A union of finite southwest rectangles is the threshold of the continuous coordinatewise nondecreasing map min_q max(x−a_q,y−b_q), so these are close for the pure downset extrema too. Do not claim invention of Fréchet bounds or extremal ordered coupling.
- [Aigner–Dowling (1971; authors' preprint, Thm. 6)](https://repository.lib.ncsu.edu/server/api/core/bitstreams/cff94333-05e8-4143-8b73-be86b165c8a4/content) explicitly has the exact fixed-graph two-sided matroid rank cut, stronger in treating arbitrary stock matroid too; [Rado (1942)](https://doi.org/10.1093/qmath/os-13.1.83) earlier gave independent representatives. No novelty for the fixed-graph assignment/matroid duality.
- [Two perishable inventory systems with one-way substitution](https://link.springer.com/article/10.1007/s10479-016-2128-1), [Dalalah (2025)](https://www.sciencedirect.com/science/article/pii/S036083522500484X), and [Ou et al. (2026)](https://onlinelibrary.wiley.com/doi/full/10.1002/nav.70081) treat concrete replenishment, cost, and substitution or freshness allocation. These are not a report-based all-linkages certificate on a single initial stock; see also [2026 substitution/emergency order comparator](https://doi.org/10.1177/10591478261426078) for the distinction from applied replenishment policy.
- No exact joint-stock matching/fixed-domain adverse-menu theorem located in this bounded search. Recommend only a narrowly scoped methods artifact, explicitly a composition of classical ideas, emphasizing the common virtual matchability system, exact protected mix, and necessary N-scenario menu. No empirical estimate, policy claim, practice change or priority assertion.
