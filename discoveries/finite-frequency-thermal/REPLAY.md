# Offline replay

Run python verify.py using Python 3. No download or package install is needed. Compare stdout with replay.txt. sha256sum -c manifest.sha256 checks the package.

The script uses exact rational arithmetic and checks two finite physical stars by direct complex thermal phasors, not just equality of fitted moments. It verifies the two-frequency estimator coefficients, a known-positive-rate-band equality pair, and a finite-rate-ceiling fixed datum with arbitrarily small positive lower rates. A nonstar network is checked independently by solving its coupled phasor equations and comparing the equivalent spectral star.

PROOF.md contains the continuous theorem, worst-case and fixed-datum sharpness, diffusion-column reduction, and deterministic calibration qualifications. No historical climate dataset was fit and no statement about actual global climate feedback is made.
