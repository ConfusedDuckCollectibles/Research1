# Offline exact replay

Run python verify.py (Python 3 standard library only). Compare the result with replay.txt. Run sha256sum -c manifest.sha256 for artifact integrity.

The oracle advances explicit rational monomials in the continuum projected angular coordinate rather than discretizing velocities. For finite positive observation time it bounds the propagator truncation by an operator norm remainder and the ballistic reference and sharp cone coefficients by alternating rational series. Removing the normal collision term gives an exact positive-path comparison, and independent low-order polynomial evaluations verify the short-time collision check.

The theorem tests a specific same-time, same-axis, energy-defined measurement contract and stationary positive-path kinetics. No existing observation was fit or reclassified.
