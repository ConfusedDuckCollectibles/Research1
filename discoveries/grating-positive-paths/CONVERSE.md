# Exact fixed-time characterization of the positive-path null

This is a companion to [the frozen two-grating proof](PROOF.md). It characterizes the *whole* feasible set at one matched observation time. It does not assume this set is the set of responses of a particular collision operator.

## 1. Which time-averaged velocities are possible?

Fix a time \(t>0\), an independently calibrated bound \(V>0\), and the law \(\alpha\) of the dimensionless projected mode velocity \(A=v/V\) prepared and read out with the equilibrium heat-capacity weights. In [the original notation](PROOF.md), \(\alpha\) is the pushforward of \(\pi\) under \(v\mapsto v/V\). All variables below take values in \(I=[-1,1]\). For a jointly measurable velocity path \(W_s\) in units of \(V\), define its normalized displacement \(Z_t=t^{-1}\int_0^t W_s\,ds\). The real grating response at \(c=qVt\) is \(E[\cos(cZ_t)]\).

For probability measures on \(I\), write \(\nu\preceq_{\rm cx}\alpha\) if \(\int h\,d\nu\le\int h\,d\alpha\) for every continuous convex \(h\) on \(I\). Affine functions of either sign are allowed, so the means must agree.

**Theorem.** The laws of \(Z_t\) generated by jointly measurable strictly stationary paths with marginal \(\alpha\) are exactly the laws \(\nu\preceq_{\rm cx}\alpha\). The same set is obtained if one requires time-reversal invariance in law, or if one weakens stationarity to having \(\alpha\) only as the marginal averaged over \([0,t]\).

*Necessity.* Average over all times in the observation window and apply Jensen on each path: for convex \(h\), \(E[h(Z_t)]\le t^{-1}\int_0^t E[h(W_s)]ds=\int h\,d\alpha\). This proves necessity for the weakest assumption.

*Sufficiency and an explicit path.* By [Strassen's martingale coupling theorem, Theorem 8](https://doi.org/10.1214/aoms/1177700153), take \(Z\sim\nu\) and a conditional probability kernel \(K_z\) on \(I\) with mean \(z\) for \(\nu\)-almost all \(z\) and mixture \(\int K_z\,d\nu(z)=\alpha\). The spaces are compact Borel intervals, so an ordinary measurable disintegration suffices. Write
\[
 Q(z,r)=\inf\{x\in I:K_z([-1,x])\ge r\},\qquad 0<r<1 .
\]
The kernel property makes this jointly measurable: at any test value \(x\), \(Q(z,r)\le x\) iff \(r\le K_z([-1,x])\). Give \(Q\) bounded, measurable values at \(r=0,1\), which do not affect the laws or the time integrals. For \(U\) uniform on the phase circle \(\mathbb R/\mathbb Z\), independent of \(Z\), let
\[
 p(u)=2\min(\{u\},1-\{u\}),\qquad
 W_s=Q(Z,p(U+s/t)).
\]
The triangular phase map \(p\) sends a uniform phase to a uniform point of \([0,1]\). At each time, conditionally on \(Z=z\), \(W_s\) has law \(K_z\), so the (unconditional) marginal is \(\alpha\). A common shift of all times merely translates \(U\), proving strict stationarity. Since \(p(-u)=p(u)\) on the circle and \(-U\) is also uniform independent of \(Z\), all joint laws are invariant under reversing time. For any starting time \(b\), the path for \(s\in[b,b+t]\) goes through exactly one full period, giving
\[
 \frac1t\int_b^{b+t}W_s,ds
    =\int_0^1 Q(Z,r)\,dr=Z\quad\text{almost surely}.
\]
This proves exact attainment, with no limit, approximation, or requirement of atoms in \(\nu\) or \(\alpha\). If physical time reversal is taken to reverse the sign of velocity as well, and \(\alpha\) is symmetric, an independent fair global sign can be applied to the path. This produces the same **real** grating response and law of the symmetric part of \(Z_t\); it does not necessarily preserve an asymmetric specified \(\nu\).

The construction is an abstract positive-carrier process. It can depend on the chosen observation time, can store the phase and latent \(Z\), and need not be mixing, ergodic, or Markov in velocity alone. It is not a realization by a given phonon collision kernel. In particular, fixed-time membership at several times does not give a joint fit by one process. For instance, strict stationarity already implies \(\operatorname{law}(Z_{nt})\preceq_{\rm cx}\operatorname{law}(Z_t)\) at positive integer \(n\), by applying Jensen to the average of the \(n\) equal-duration consecutive displacements.

## 2. Full set for any finite set of matched gratings

For any \(m\) wave numbers \(c_j\), all along the same axis at the same true time and using the same calibration, the full set of real grating transfers is
\[
 \mathcal T_\alpha=\left\{
     \left(\int_I\cos(c_jx)d\nu(x)\right)_{j=1}^m:
      \nu\preceq_{\rm cx}\alpha
 \right\}.
\]
This set is compact and convex: probability measures on the compact interval are weakly compact, all convex-order constraints are closed, and the map to the transfer vector is continuous and affine. This characterization works beyond the positive-curvature window used by the simple two-grating inequality.

An exact way to get any supporting hyperplane is to choose real weights \(w_j\), set \(F(x)=\sum_j w_j \cos(c_jx)\), and use
\[
 \boxed{\quad
   \max_{\nu\preceq_{\rm cx}\alpha}\int_I F\,d\nu
    =\inf_{\substack{h\in C(I),\ h\,\mathrm{convex}\ h\ge F}}\int_I h\,d\alpha .
 \quad}                                                                 \tag{C1}
\]
To prove (C1), let \(\nu\) range over all probability measures and \(h\) over the cone of continuous convex functions, and consider \(\int F\,d\nu+\int h\,d(\alpha-\nu)\). The infimum over \(h\) is \(\int F\,d\nu\) for feasible \(\nu\), and \(-\infty\) otherwise by positive rescaling of a violated constraint. The expression is continuous affine in \(\nu\) (weak topology) and in \(h\) (uniform norm); the first set is compact convex and the second is convex. [Sion's minimax theorem](https://doi.org/10.2140/pjm.1958.8.171) swaps the supremum and infimum. Now the supremum over \(\nu\) is \(\int h\,d\alpha+\max_I(F-h)\), from maximization over point masses. This equals the cost of the continuous convex majorant \(h+\max_I(F-h)\). Conversely any majorant is an upper bound by convex order. This proves (C1) without assuming that the infimum is attained.

A measured transfer vector \(y\) belongs to \(\mathcal T_\alpha\) if and only if \(\sum_jw_j y_j\) is no larger than (C1) for every real vector \(w\); this follows by finite-dimensional separation. Every single verified convex majorant gives a one-sided obstruction, and using \(-w\) gives the other side. For a finite discrete velocity calibration, it suffices in (C1) to optimize over continuous convex piecewise linear functions with knots at the calibrated velocities, working on the convex hull of that support. Convex order forces all feasible \(\nu\) into that hull (apply the convex distance to the hull); the secant interpolant over the knots of any convex majorant lies above it and does not change its integral against \(\alpha\). The constraint that this piecewise linear function majorizes \(F\) is still a continuum condition on each interval.

There is an equivalent expression for the residual itself. Set
\[
 H(a)=E[(A-a)_+]-E[(Z_t-a)_+] .
\]
Under the theorem \(H\ge0\), \(H\) is zero outside \(I\), and \(H''=\alpha-\nu\) as distributions on the real line. Conversely, a continuous nonnegative \(H\) vanishing outside \(I\) with \(\alpha-H''\) a nonnegative measure defines such a \(\nu\): test the second derivative on smooth functions equal near \(I\) to \(1\) and \(a\) to recover equal mass and mean. This potential is the hinge-integral difference of those laws, because both functions have the same distributional second derivative and vanish off \(I\). Tests against affine functions and hinges, followed by polygonal approximation, then give convex order. Integration against the second derivative of \(-\cos(ca)/c^2\) shows
\[
 \frac{D(c)}{c^2}=\int_{-1}^1 H(a)\cos(ca)\,da \qquad (c\ne0).
\]
Thus different gratings test the same constrained nonnegative potential, not an independently chosen defect at each wave number.

## 3. What is sharp in the short two-grating rule?

For \(0<c_1<c_2<\pi/2\), write residual coordinates as \(d_j=D(c_j)/c_j^2\). The inequalities in [the frozen proof](PROOF.md) describe the **closed conic hull of attainable residual vectors when the calibration is uniform on \([-1,1]\)**, not the attainable vector set itself. To see this, all residual vectors lie in the cone by the curvature ratio proof. The localized reversible reset examples approach both bounding rays after normalization to \(d_1=1\). Because the closure of a conic hull is a closed convex cone, it contains the sector between those rays. The feasible set itself is bounded and can have additional nonlinear restrictions. With other calibrated marginals, the inequalities remain valid, but the sharp conic hull can be smaller.

For an exact illustration take \(\alpha=(\delta_{-1}+\delta_1)/2\), and \(c_2=2c_1<\pi/2\), \(a=\cos c_1\). All mean-zero laws on \([-1,1]\) are convex-dominated by \(\alpha\) by comparison with the chord through the endpoints. Put \(Y=\cos(c_1Z_t)\in[a,1]\). Conversely *any* law of \(Y\) in that interval comes from a feasible symmetric law of \(\pm\arccos(Y)/c_1\) using an independent fair sign. Therefore the exact raw-residual band is
\[
 0\le D(c_1)\le1-a,\qquad
 4aD(c_1)+2D(c_1)^2\le D(c_2)\le 2(1+a)D(c_1).
\]
Indeed \(D(c_1)=EY-a\) and \(D(c_2)=2(EY^2-a^2)\). The lower and upper second moments at fixed first moment are attained by a point mass and the endpoint distribution, respectively; mixtures at that mean attain everything between. For example \(a=3/4\), \(D(c_1)=1/8\), \(D(c_2)=3/8\) obey the short cone and both individually possible ranges, but violate the sharper lower limit \(13/32\). This is an illustrative calibration, not a material model or a second empirical witness. See [the exact control](verify_converse.py).

## 4. Interpretation for a calibrated experiment

Use equal true time after a matched impulsive perturbation, one wavevector axis, a shared velocity calibration and ballistic baseline, and a normalization relating *both* optical signals to the normalized energy modulation with the same modal preparation/readout weights. A freely chosen gain, timing offset, projected velocity law, or heating/readout profile per grating destroys this comparison. An arbitrary optical intensity trace is not the real signed energy response; the measurements must establish that mapping.

Under independently justified joint bounds on the calibration and science observables, reject the null only if no admissible jointly varied calibration is compatible with the measured-response uncertainty set. In particular a lower-cone rejection can be robustly certified by a strictly positive lower bound under those jointly varied nuisance values for
\[
 \left(\frac{c_2}{c_1}\right)^2\frac{\cos c_2}{\cos c_1}(\Theta_1-B_1)
          -(\Theta_2-B_2),
 \qquad 0<c_1<c_2<\pi/2.
\]
The synthetic [continuum Callaway witness](PROOF.md) bounds this score from below by 0.0013 when the calibration is exact. Its illustrated tolerance of \(4\times10^{-4}\) per residual uses an absolute error box under *fixed dimensionless wave numbers and exact cosine factors*; no independence of statistical errors is needed for that deterministic statement. Neither this tolerance nor the abstract converse claims that existing measurements reach the required physical calibration.

A violation rejects the stated broad positive-path null, including its stationary energy-conserving single-mode relaxation submodels. It does not identify the physical cause uniquely. A match establishes compatibility only for an abstract positive path at that observation time; it does not establish absence of collective behavior or verify a specific kinetic mechanism.
