# Matching heat and sea level can still leave overturning uncertain

How much circulation could two balanced ocean sections hide while matching the same heat and freshwater transport, sea-surface height, and bottom pressure? In the prescribed idealized setting here, the answer at the midpoint of a specified depth band has an exact upper bound. The proof constructs a pair that reaches it and has its flow peaks at the same depth.

In the illustrative 1,800 m band, a declared 0.30 kg/m³ allowance on the difference between the two east-to-west boundary density contrasts permits a **2.112 Sv** difference in peak overturning (about 2.112 million cubic meters per second). That allowance is an input to the model, not a measured sensor error or a claim about the real Atlantic. Direct full-depth boundary density data can resolve this ambiguity.
