# Offline exact replay

Run python verify.py with Python 3 (standard library only). Compare stdout with replay.txt. Use sha256sum -c manifest.sha256 to verify the four files.

The code independently enumerates bounded unit-slot binary/trinary histories and solves their exact scalar reflected storage dynamics, then compares the resulting cut statistics with the continuous cut formula. The proof reduces the relevant continuous controls to integer-vertex cuts in these examples, so they are not generic fine-grid approximations. The positive-mean no-finite-store example is checked by an exact rational sign.

No real grid, site, power-system data, operating action, statistical forecast or design recommendation is involved.
